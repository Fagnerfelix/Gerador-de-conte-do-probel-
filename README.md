# Diretor Comercial IA — Probel

MVP de uma central de inteligência comercial para transformar informações de parceiros, produtos, vendedores e campanhas em ações práticas.

## Primeira versão

- Dashboard executivo
- Visão de parceiros estratégicos
- Área de produtos preparada para evolução
- Copiloto de IA comercial
- Endpoint server-side para integração com OpenAI
- Interface responsiva para desktop e celular

## Rodando localmente

1. Instale Node.js 20+.
2. Execute `npm install`.
3. Copie `.env.example` para `.env.local`.
4. Configure `OPENAI_API_KEY`.
5. Execute `npm run dev`.
6. Abra `http://localhost:3000`.

## Visão de produto

O objetivo é evoluir o sistema em módulos:

1. Visão Executiva — indicadores, prioridades e alertas.
2. Parceiros — histórico, mix, oportunidades, visitas e próximos passos.
3. Produtos — ficha técnica, benefícios, argumentos e objeções.
4. Diagnóstico de Sono — perguntas consultivas e recomendação de produto.
5. Vendedores — metas, desempenho, treinamento e coaching.
6. IA Comercial — campanhas, roteiros, análises e recomendações.
7. CRM e automações — acompanhamento de oportunidades e tarefas.

## Princípio central

A IA não deve apenas gerar conteúdo. Ela deve ajudar o gestor a decidir onde agir, quem desenvolver, qual parceiro priorizar, qual produto posicionar e qual ação comercial executar em seguida.
